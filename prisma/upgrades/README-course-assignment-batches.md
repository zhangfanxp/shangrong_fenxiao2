# 课程分配记录：数据库升级与验收

本次代码将“一次课程分配操作”保存为一个批次。部署前必须升级数据库；只更新前端或只生成 Prisma Client 不会创建数据表。

## 部署

1. 备份现有 MySQL 数据库，暂停课程分配和学习进度写入。
2. 核对目标数据库后执行一次增量 SQL（适用于升级前尚未有批次表的现有库）：

   ```sh
   npx prisma db execute --file prisma/upgrades/20260831_course_assignment_batches.sql --schema prisma/schema.prisma
   npx prisma generate
   ```

   脚本新增批次、课程快照、用户快照、品牌/门店范围和编号序列表；保留原 CourseAssignment 数据，将唯一约束改为“批次 + 课程 + 用户”。学习进度仍以“课程 + 用户”唯一。不删除课程、用户或进度。MySQL DDL 不支持整段事务回滚，脚本不可重复执行；如已部分执行，先核对数据库结构，不要强行重跑或重置数据库。

3. 预览旧分配关系，再选择是否补录：

   ```sh
   node --env-file=.env --import tsx scripts/backfill-course-assignment-batches.ts
   node --env-file=.env --import tsx scripts/backfill-course-assignment-batches.ts --apply
   ```

   原系统只保存去重后的“课程—用户”关系，无法准确还原某次操作所选的全部课程/用户，也无法恢复原始名称或封面。补录不会猜测合并：一条旧关系生成一条标记为 `legacyImported` 的记录，日期和分配人沿用原关系，课程/用户资料取补录时快照。详情会明确说明它不是原始操作批次。默认只读，`--apply` 才写入；可重复运行或从中断处继续。

   未补录的旧关系仍可用于移动端学习，但不会出现在批次列表，也不能按批次启停。要统一管理旧分配，应在上线前完成补录。补录按原关系日期申请当日流水号；单日超过 9999 条会安全失败，需要先确认历史数据处理策略。

4. 为相关角色勾选“课程分配记录-查询/查看/查看学习记录/停用/启用/批量停用/批量启用”。超级管理员和原 `training:view` 兼容权限继续可用。仅有 `courses:*` 不再隐式获得本模块的用户数据访问权。
5. 执行后续[课时学习记录升级](./README-lesson-learning-visits.md)，再构建、重启服务后恢复访问。本版新增逐次进入明细表，不能仅执行批次升级后启动新版服务。

## 业务边界

- 新分配仅支持已启用课程：禁用课程的勾选框不可选，全选自动跳过；服务端发现任一所选课程已禁用时拒绝整次分配，不生成部分批次。
- 课程名称和分配人员均查询分配时快照；日期按上海时区整日范围，截止日期使用次日零点的排他上界。
- 不展示状态列；操作列根据批次状态显示启用/停用。批量操作逐条事务，返回成功、跳过与失败原因。所有启停提交当前版本，过期操作返回冲突。
- 当前管理员的品牌/门店范围使用现有用户配置及 `data:brand:*` / `data:store:*` 规则。混合范围批次仅向能管理全部接收人的管理员展示；不会只展示部分用户却允许停用整批。
- 同一用户只要还有一个启用批次（或未补录旧关系）分配该课程，仍具备资格。课程本身禁用/删除、用户或角色禁用时不可学习。两套移动端的列表、详情、文件和进度写入均校验资格。
- 进度采用共享记录。有效秒数大于 0 或课时完成才记录首次学习时间；仅打开页面、提交零秒不计已学习。“学习记录”现在单独按每次进入课时展示，包括未产生有效进度的访问；“未学习人员”仍按有效学习判断。旧进度不能还原逐次进入和退出时间，明细中标记为历史数据未采集。
- 文件地址是分配时封面快照；失效时回退系统默认课程封面。已签发的短期资源链接不能即时撤销，但后续课时/资源/进度请求会重新校验。

## 测试

测试脚本拒绝非本机或非 `canyin_assignment_test_*` 数据库，并要求用户表为空。请使用专用测试库的 `DATABASE_URL`，先应用 schema，然后运行：

```sh
npx tsx scripts/verify-course-assignments.ts
npx tsc --noEmit
npm run build
```

覆盖批次原子写入与中途失败回滚、批内去重、幂等重试、并发编号、重复分配、最后有效批次停用、详情/课时/封面/进度拒绝访问、乐观锁、有效学习口径、批次接收人范围、历史名称和封面、启停保留进度、课程/用户禁用、品牌门店隔离、日期及权限规则，以及批量成功/跳过/版本冲突同时出现的部分成功结果。浏览器验收需另用授权账号完成列表、筛选、详情与批量操作交互。
